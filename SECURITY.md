# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/semmidev/otelkit/security/advisories/new).

Include the affected version, a reproduction, and the impact you expect. We aim
to acknowledge reports within a few business days and to ship a patch as soon
as the fix is verified.
